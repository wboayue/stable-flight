# The heading in the wind decides the eXplora's landing roll cycle

**Measured:** 2026-10-21, RealFlight, eXplora, 5 km/h wind from about 37°, hover descent
(land). **Data:** #476.

A land thrust step looked like what set off a roll cycle (±12–16° at 1.2 s, roll rate D 0).
Main and the fix cycled alike; the heading decided it: at 145°, the wind about 20° behind the
wingtip, it cycled, and at 125°, a wingtip square into the wind, it never did. Roll rate D 0.03
stops it.

**So:** before crediting a fix with a flight behavior, fly main on the same route with the
heading relative to the wind held and reported.
